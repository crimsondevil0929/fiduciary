# Fiduciary

Signed mandates, quorum warrants and offline compliance proofs for AI agents, over
[AgentGov](https://pypi.org/project/interlock-agentgov/) (the budget ledger) and
[Interlock](https://pypi.org/project/interlock-escrow/) (the side-effect reference
monitor).

`docs/FIDUCIARY_SPEC.md` is the specification. This is release 0.1.0, Phase 1 of its
roadmap.
